    Archive model?
    
        
    
          Archive pauses and retains this model read-only. It leaves every Flow
          model list and new tasks never select it. Already claimed tasks keep
          their model and key; historical tasks remain. The name stays reserved.
          Unarchive returns it active but does not restore Flow selections.
        
    
        
    
          Archive is available only when no Flow depends on this as its sole
          model. A sole-model Flow blocks this action; add another model to that
          Flow first.
        
    
        
    
        
    
        
    
          
        
    
      
    
        
    
      
    
        
    Unarchive model?
    
        
    
          The model returns to Current models as Active with its configuration
          and key. It is not automatically added to any Flow; historical task
          keys are not restored.
        
    
        
    
        
    
        
    
          
        
    
      
    
        
    
      
    
        
    Pause model?
    
        
    
          Running tasks keep this model. New tasks of Flows with no other active
          model wait in Pending. This model stays in Current models.
        
    
        
    
        
    
        
    
          
        
    
      
    
        
    
      
    
        
    Resume model
    
        
    
          The paused model returns to active selection. Newly claimed tasks may
          use it according to each Flow’s model order.
        
    
        
    
        
    
          
        
    
      
    
        
    
      
    
        
    Cancel task
    
        
    
          The request goes to the assigned Executor. This run may take time to
          stop.
